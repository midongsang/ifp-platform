## 二、收益项（年度预估）

### 收益 1：减少资损损失

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 历史年均规则类资损金额 | A | |
| 引入 IFP 后规则类资损下降比例 | R1（如 40%） | |
| **资损减少收益** | A × R1 | |

### 收益 2：线上故障排查与修复人力节省

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 年均规则类故障数量 | N | |
| 单次故障平均人力成本（人天） | D | |
| 人均单日人力成本 | C | |
| 故障减少比例 | R2（如 50%） | |
| **故障人力收益** | N × D × C × R2 | |

### 收益 3：审计取证人力节省

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 每年审计次数 | M | |
| 单次审计人工整理证据人天 | T | |
| 人均单日人力成本 | C | |
| **审计人力收益** | M × T × C | |

### 收益 4：需求沟通返工节省

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 年均因规则歧义导致需求返工次数 | K | |
| 单次返工人天 | S | |
| 人均单日人力成本 | C | |
| **返工节省收益** | K × S × C | |

年度总收益 = 收益 1 + 收益 2 + 收益 3 + 收益 4

## 三、成本项（年度预估）

### 成本 1：平台研发 / 采购成本

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 平台研发人力投入（人月） | DevM | |
| 人均月成本 | DevCost | |
| **平台建设成本** | DevM × DevCost | |

### 成本 2：建模人力成本（业务、产品、开发建模与评审）

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 建模总投入人月 | ModelM | |
| 人均月成本 | ModelCost | |
| **建模人力成本** | ModelM × ModelCost | |

### 成本 3：基础设施运维成本

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 服务器、存储、监控、运维人力 | InfraCost | |

### 成本 4：培训、流程建设成本

| 参数 | 符号 | 取值 |
| --- | --- | --- |
| 培训、文档、评审流程建设 | TrainCost | |

年度总成本 = 平台建设成本 + 建模人力成本 + InfraCost + TrainCost

---

## 四、ROI 计算公式

1. **净收益 = 年度总收益 − 年度总成本**
2. **ROI = 净收益 ÷ 年度总成本 × 100%**

---

## 五、定性收益（无法直接量化，汇报时补充）

- 业务规则统一可信源，减少跨团队沟通冲突；
- 合规内控能力提升，满足监管审计要求；
- 规则变更风险可视化，降低重大变更失控风险；
- 沉淀业务领域模型，便于新人理解业务逻辑。

## 六、敏感性分析

可调整以下参数，观察 ROI 变化：

| 变量 | 说明 |
| --- | --- |
| 资损下降比例 R1 | 高估/低估对 ROI 影响最大 |
| 建模人力投入 ModelM | 投入增加/减少对 ROI 影响 |
| 故障数量预估 N | 波动场景下的 ROI 区间 |
| 审计频次 M、返工次数 K | 治理类收益的敏感度 |

---

## 七、测算备注

1. IFP 仅针对**业务规则类缺陷**，不会消除所有故障；代码 bug、基础设施故障不在覆盖范围内。
2. 低风险简单 CRUD 业务，ROI 通常为负，不建议落地。
3. 试点阶段收益会低于规模化阶段，建议分阶段评估。

## 八、示例填表：电商退款域（示例数据）

以下为一份示例填表，数据只用于演示填法，实际测算请换成业务真实数据。

**基础信息**

| 字段 | 填写 |
| --- | --- |
| 业务域名称 | 电商退款域（`RefundContext`） |
| 业务类型 | 资金 / 售后 |
| 业务风险等级 | 高 |
| 测算周期 | 12 个月 |

**收益项**

| 参数 | 符号 | 示例取值 | 计算 | 收益（示例，单位：万元） |
| --- | --- | --- | --- | --- |
| 历史年均规则类资损 | A | 200 万 | — | — |
| 资损下降比例 | R1 | 40% | 200 × 40% | **80** |
| 年均规则类故障数量 | N | 10 次 | — | — |
| 单次故障人力（人天） | D | 5 人天 | — | — |
| 人均单日人力成本 | C | 0.15 万 | — | — |
| 故障减少比例 | R2 | 50% | 10 × 5 × 0.15 × 50% | **3.75** |
| 每年审计次数 | M | 2 次 | — | — |
| 单次审计整理人天 | T | 10 人天 | 2 × 10 × 0.15 | **3** |
| 年均返工次数 | K | 8 次 | — | — |
| 单次返工人天 | S | 3 人天 | 8 × 3 × 0.15 | **3.6** |
| **年度总收益** | | | 80 + 3.75 + 3 + 3.6 | **≈ 90.35** |

**成本项**

| 参数 | 符号 | 示例取值 | 计算 | 成本（示例，单位：万元） |
| --- | --- | --- | --- | --- |
| 平台研发人力 | DevM | 12 人月 | — | — |
| 人均月成本 | DevCost | 2.5 万 | 12 × 2.5 | **30** |
| 建模投入人月 | ModelM | 6 人月 | — | — |
| 人均月成本 | ModelCost | 2.0 万 | 6 × 2.0 | **12** |
| 基础设施运维 | InfraCost | — | — | **3** |
| 培训与流程建设 | TrainCost | — | — | **2** |
| **年度总成本** | | | 30 + 12 + 3 + 2 | **47** |

**ROI 结果**

| 指标 | 计算 | 示例结果 |
| --- | --- | --- |
| 净收益 | 90.35 − 47 | **43.35 万元** |
| ROI | 43.35 ÷ 47 × 100% | **≈ 92%** |

结论（示例）：该退款域试点一年就接近盈亏平衡并产生正向回报，收益大头来自资损减少。
随着建模规范沉淀、模型在多域复用，规模化阶段的 ROI 通常还会往上走。
